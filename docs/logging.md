# 日志系统

## 1. 日志等级

- 支持四个日志等级：DEBUG、INFO、WARN、ERROR
- 每个等级需支持三种输入类型：
  1. 纯字符串输入
  2. 带格式化占位符的字符串输入(如"name is %s", name)
  3. 自定义JSON字符串输入

## 2. 日志中间件

### 2.1 Gin日志中间件

- HTTP日志使用独立的日志文件（logs/http.log）
- 应用日志使用独立的日志文件（logs/app.log）

### 2.2 日志内容

记录以下请求信息：
- 调用者身份（user_id）
- 请求方法（method）
- 请求路径（path）
- 查询参数（query）
- 响应状态码（status）
- 请求处理时间（latency）
- 客户端IP（client_ip）
- 用户代理（user_agent）

## 3. 日志文件管理

### 3.1 文件配置

- 使用lumberjack进行日志轮转
- 单个日志文件最大大小：100MB
- 保留最多10个旧日志文件
- 日志文件压缩：启用

### 3.2 日志目录结构

```
logs/
├── http.log      # HTTP请求日志
├── app.log       # 应用日志
└── audit.log     # 审计日志（可选）
```

## 4. 审计日志

### 4.1 审计内容

- 权限变更操作
- 用户角色分配/移除
- 角色权限分配/移除
- 敏感数据访问

### 4.2 审计字段

- 操作时间
- 操作者身份
- 操作类型
- 目标资源
- 操作结果
