数据中心系统 · 前端风格 Template 对比选型

以下 4 套为「视觉方向」演示稿（同一数据的仪表盘 + 数据列表），用来让你确认整体风格基调。选定方向后，我会据此输出完整的 HTML 设计稿（登录、各页面、组件、响应式、主题变量）。

模板 A

深空数据台 · Dark Console

深色主题 / 高密度 / 等宽数字 / 监控感。面向 OPC/工程数据的「操作台」气质。
适合：全天盯屏、信息密度高、工程/监控场景
模板 B

明亮企业风 · Light SaaS

白底浅灰 / 克制的蓝 / 圆角卡片 / 大量留白。现代 SaaS 产品观感（类 Linear/Jira Cloud）。
适合：多数团队、商务友好、通用性最强
模板 C

渐变玻璃风 · Gradient Glass

浅底 + 渐变光效 + 毛玻璃卡片 + 彩色高亮。更现代、更「科技感」的升级版玻璃风。
适合：想保留「玻璃质感」但更现代、更高级的团队
模板 D

极简工程风 · Flat Minimal

近单色 / 高对比 / 锐利边缘 / 信息密集。克制、专注、工程工具感（Unity/Linear 工具风）。
适合：追求简洁、专业、数据为重、厌弃花哨的团队
说明与建议： ① 这 4 套刻意做成截然不同的基调，便于对比——请从配色（深/浅）、密度（信息量）、质感（玻璃/渐变/扁平）、性格（监控/SaaS/科技/极简）几方面挑一个你最认同的。
② 如果你喜欢某个方向但想微调（比如「要 B 的浅色，但左侧栏换成 C 的渐变」，或「要 D 的极简，但加强状态色」），告诉我，我会在此基础上生成最终设计稿。
③ 选定后，完整设计稿将覆盖全部页面（登录、仪表盘、DQL 查询、集合管理、集合详情、刮削管理、权限管理、个人设置、数据项详情/关联/血缘、弹窗、Toast、表格、表单、主题变量），并可直接接入现有 go:embed 前端代码。
